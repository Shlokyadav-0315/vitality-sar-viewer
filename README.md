# Vitality - Dancing with the SARs

**NASA Space Apps Challenge 2026** | Challenge: "Dancing with the SARs"

🌍 [**Live Demo**](https://vitality-sar-2026.surge.sh/)

---

## 🎯 Project Overview

Vitality is an interactive web visualization that showcases Earth's surface changes using NASA-ISRO SAR (Synthetic Aperture Radar) mission data. Track glacier retreat, deforestation, and climate impacts through stunning 3D visualizations and real satellite imagery.

---

## ✨ Features

- 🌍 **3D Earth Visualization** - Interactive rotating globe with orbiting moon
- 🛰️ **SAR Technology Explanation** - Learn how radar satellites monitor Earth
- 🏔️ **Jakobshavn Glacier Timeline** - Track 37 years of ice loss (1985-2022)
- 📊 **Climate Impact Analysis** - Understand global consequences
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 🎨 **Modern Space-Tech Design** - Professional aerospace aesthetic

---

## 🛠️ Tech Stack

- **React 18** - UI framework
- **Three.js** - 3D graphics rendering
- **React Three Fiber** - React renderer for Three.js
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Surge.sh** - Deployment

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/vitality-sar-viewer.git

# Navigate to project directory
cd vitality-sar-viewer

# Install dependencies
npm install

# Start development server
npm run dev
```

Open http://localhost:5173 in your browser

### Build for Production

```bash
npm run build
```

## 🎓 About the Challenge

**NASA Space Apps Challenge 2026** - "Dancing with the SARs"

Create innovative visualizations of SAR data to help understand Earth's changing surface and climate impacts. This project demonstrates how satellite radar technology reveals environmental changes invisible to optical cameras.

**Location Focus:** Jakobshavn Glacier, Greenland (69.17°N, 49.83°W) - one of the fastest-moving glaciers on Earth and a major contributor to sea level rise.
